# Stämpel

Windows-appen för timern i Process Studio. Det här repot innehåller bara
releaser; källkoden finns i ett privat repo.

## Installera

1. Ladda ned `Stampel-win-Setup.exe` från den [senaste releasen](https://github.com/Eqviva/stampel/releases/latest).
2. Kör filen. Windows kan varna eftersom filen inte är kodsignerad: välj
   **Mer information** och **Kör ändå**.
3. Stämpel installeras för din användare, startar med Windows och syns som en
   klocka i systemfältet. Välj **Logga in** och bekräfta i webbläsaren.

Stämpel uppdaterar sig själv från detta repo med Velopack. Avinstallera under
**Inställningar → Appar → Installerade appar**.
